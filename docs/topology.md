# Network Topology Reference

**Project:** Namma Pulse – Phase 0  
**Document:** Topology Reference

---

## Overview

The Phase 0 operational network covers three metro lines:

| Line | Colour | Terminals | Stations | Length |
|------|--------|-----------|----------|--------|
| Purple | 🟣 | Whitefield (Kadugodi) ↔ Challaghatta | 36 | ~43.5 km |
| Green | 🟢 | Madavara ↔ Silk Institute | 32 | ~33.5 km |
| Yellow | 🟡 | RV Road ↔ Bommasandra | 16 | 19.15 km |

**Total Phase 0 nodes:** 84  
**Total Phase 0 edges:** 83 (81 line edges + 2 interchange transfer edges)
